## 🎯 The Vision
I am a pre-college student utilizing the transition period before my first semester to build a rigorous foundation in **Computer Science Fundamentals**. This repository serves as a transparent, daily log of my journey into low-level programming and logical optimization.

## 🛠️ The Toolkit
* **Core Language:** C++ (Focusing on Memory Management & Efficiency)
* **Logic Building:** Striver’s A-Z DSA Framework
* **Environment:** VS Code + MinGW (GCC)
* **Goal:** To enter my undergraduate program with industry-standard coding discipline.

---

## 📅 Roadmap to Mastery

### 🏗️ Block 1: The Engine (Days 1–30)
* Deep dive into C++ Syntax and Data Types.
* Mastering Control Flow and Iterative Logic.
* **Goal:** Transitioning from "writing code" to "thinking in algorithms."

### 🧩 Block 2: Architectural Thinking (Days 31–60)
* Object-Oriented Programming (OOP) Fundamentals.
* Introduction to the C++ STL (Standard Template Library).
* **Goal:** Writing modular, reusable, and clean code.

### 🚀 Block 3: Algorithmic Rigor (Days 61–100)
* Time and Space Complexity Analysis.
* Linear Data Structures (Arrays, Linked Lists, Stacks, Queues).
* **Goal:** Solving real-world problems with optimal efficiency.
